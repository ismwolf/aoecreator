# A.T6 — packages/shared Zod ↔ Pydantic Parity Plan
Date: 2026-05-15

## Goals
- Stand up `packages/shared/` as a workspace package named `@aeogen/shared`, exporting Zod schemas to TS consumers (apps/web) AND emitting matching Pydantic v2 models for Python consumers (apps/api) via JSON Schema as the language-neutral bridge.
- Lock in the **Zod-first + codegen** parity strategy: TS is source of truth → JSON Schema emit → `datamodel-code-generator` writes Pydantic models. No hand-maintained Python schemas.
- Ship **2 example schemas** end-to-end as proof-of-concept: `Site` and `Workspace` (from master plan §4.B / §10). Full domain modeling is deferred to Faz 2 B alongside the first real consumer.
- Wire a deterministic build pipeline: `pnpm --filter @aeogen/shared build` runs `tsc` → emits JSON Schema files → spawns `datamodel-code-generator` → writes Python models with a `# DO NOT EDIT` header.
- Ship cross-side parity test: TS Vitest test parses a known-good fixture through `SiteSchema.parse()`, Python pytest parses the **same fixture file** through `Site.model_validate()`. Both must succeed against the same JSON bytes.
- Ship drift-detection: a script (or pytest assertion) that re-runs codegen and fails if `git diff --quiet packages/shared/python` is non-zero — i.e., committed Python is out of sync with current Zod source. CI-runnable today; pre-commit hook wire-up deferred to A.T10.
- Verify: `pnpm install`, `pnpm --filter @aeogen/shared build`, `pnpm --filter @aeogen/shared test`, `pnpm --filter @aeogen/shared lint`, `pnpm --filter @aeogen/shared typecheck` all pass. From `packages/shared/python`: `uv run pytest tests/` green. Drift check exits 0.

## Non-goals
- **No full domain modeling.** Organization, OrgMember, Workspace_Member, Site (full), Page, AnalysisRun, AgentExecution, Score, Embedding, AgentMemory, AgentSkill, AuditLog — these land with their first consumer in Faz 2 B (per master plan §4.B + §5 data model). This task only delivers the **machinery + 2 examples** so the next task can extend the pattern.
- No RLS-aware schemas (org_id / workspace_id discriminators that pair with Postgres RLS predicates) — Faz 2 B.
- No JWT / auth payload schemas (`app_metadata.org_id`, `role`, `workspace_ids`) — Faz 2 G.
- No FastAPI request/response DTOs (Pydantic models with FastAPI-specific `Field(...)` aliases, OpenAPI `examples=`, response envelopes) — Faz 3+ when API routes start landing.
- No form-input vs API-input split (`SiteCreateInput` vs `SiteRow`) — Faz 6 F when forms appear.
- No OpenAPI / Swagger generation — Faz 3+.
- No `zod-to-prisma` / Supabase types integration — A.T8 will run `supabase gen types typescript` separately into `apps/web/src/lib/database.types.ts`. `packages/shared` and `database.types.ts` are intentionally disjoint contracts: shared = cross-language DTOs, database.types = generated Supabase row types.
- No pre-commit hook for drift check — A.T10 will wire Husky / `pre-commit`. This task ships the SCRIPT; A.T10 wires the HOOK.
- No GitHub Actions wiring — A.T12. Plan documents how to invoke from CI but does NOT add `.github/workflows/`.
- No editable install of `aeogen-shared` into `apps/api` yet — apps/api never imports a Pydantic model in this task. Open Q3 documents the path; actual wire-up happens when the first apps/api code imports `from aeogen_shared import Site` (Faz 2 B or later).

/**

 * Source of truth for the cross-language `Site` DTO. Pydantic version

 * hand-edit packages/shared/python/aeogen_shared/site.py.

export const SiteLanguageEnum = z.enum(["tr", "en", "de", "fr", "es"]);
export type SiteLanguage = z.infer<typeof SiteLanguageEnum>;

export const SiteSchema = z
  .object({

    url: z.url(),

### T6.5 — JSON Schema emit script (~5 min)

**File created:** `packages/shared/src/scripts/emit-json-schema.ts`

```ts
import { writeFile, mkdir } from "node:fs/promises";
import { resolve, dirname } from "node:path";
import { fileURLToPath } from "node:url";
import { z } from "zod";
import { SiteSchema } from "../schemas/site.js";
import { WorkspaceSchema } from "../schemas/workspace.js";

const __dirname = dirname(fileURLToPath(import.meta.url));
const OUT_DIR = resolve(__dirname, "../../dist/schemas");

interface SchemaExport {
  name: string;
  filename: string;
  schema: z.ZodTypeAny;
}

const EXPORTS: SchemaExport[] = [
  { name: "Site", filename: "site.schema.json", schema: SiteSchema },
  { name: "Workspace", filename: "workspace.schema.json", schema: WorkspaceSchema },
];

async function main(): Promise<void> {
  await mkdir(OUT_DIR, { recursive: true });
  for (const exp of EXPORTS) {
    const json = z.toJSONSchema(exp.schema, {
      target: "draft-2020-12",
      reused: "inline",
    });
    const enriched = {
      $schema: "https://json-schema.org/draft/2020-12/schema",
      $id: `https://aeogen.local/schemas/${exp.filename}`,
      title: exp.name,
      ...json,
    };
    const path = resolve(OUT_DIR, exp.filename);
    await writeFile(path, JSON.stringify(enriched, null, 2) + "\n", "utf8");
    console.log(`emit: ${exp.filename}`);
  }
}

await main();
```

**`codegen-pydantic.ts` sketch:**
```ts
import { spawn } from "node:child_process";
import { resolve, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = dirname(fileURLToPath(import.meta.url));
const SCHEMA_DIR = resolve(__dirname, "../../dist/schemas");
const PY_OUT_DIR = resolve(__dirname, "../../python/aeogen_shared");
const PKG_ROOT = resolve(__dirname, "../..");

const GENERATED_HEADER = `# DO NOT EDIT — generated by packages/shared codegen.
# Source of truth: packages/shared/src/schemas/*.ts (Zod).
# Regenerate via: pnpm --filter @aeogen/shared build
`;

interface Job { schemaFile: string; outFile: string; className: string; }
const JOBS: Job[] = [
  { schemaFile: "site.schema.json", outFile: "site.py", className: "Site" },
  { schemaFile: "workspace.schema.json", outFile: "workspace.py", className: "Workspace" },
];

function runUv(args: string[]): Promise<void> {
  return new Promise((res, rej) => {
    const p = spawn("uv", args, { cwd: PKG_ROOT, stdio: "inherit", shell: process.platform === "win32" });
    p.on("exit", code => code === 0 ? res() : rej(new Error(`uv ${args.join(" ")} exited ${code}`)));
  });
}

for (const job of JOBS) {
  const input = resolve(SCHEMA_DIR, job.schemaFile);
  const output = resolve(PY_OUT_DIR, job.outFile);
  await runUv([
    "run", "datamodel-codegen",
    "--input", input,
    "--input-file-type", "jsonschema",
    "--output", output,
    "--output-model-type", "pydantic_v2.BaseModel",
    "--target-python-version", "3.12",
    "--use-schema-description",
    "--use-field-description",
    "--use-standard-collections",
    "--use-union-operator",
    "--enum-field-as-literal", "all",
    "--use-double-quotes",
    "--disable-timestamp",
    "--custom-file-header", GENERATED_HEADER,
  ]);
  console.log(`codegen: ${job.outFile}`);
}
```

import { spawnSync } from "node:child_process";
import { resolve, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const __dirname = dirname(fileURLToPath(import.meta.url));
const PKG_ROOT = resolve(__dirname, "../..");
const REPO_ROOT = resolve(PKG_ROOT, "../..");

const emit = spawnSync("pnpm", ["run", "build:json-schema"], { cwd: PKG_ROOT, stdio: "inherit", shell: process.platform === "win32" });
if (emit.status !== 0) process.exit(emit.status ?? 1);
const codegen = spawnSync("pnpm", ["run", "codegen:python"], { cwd: PKG_ROOT, stdio: "inherit", shell: process.platform === "win32" });
if (codegen.status !== 0) process.exit(codegen.status ?? 1);

const diff = spawnSync("git", ["diff", "--quiet", "--exit-code", "packages/shared/python"], { cwd: REPO_ROOT, stdio: "inherit" });
if (diff.status !== 0) {
  console.error("\nDRIFT DETECTED: packages/shared/python is out of sync with current Zod source.");
  console.error("Run `pnpm --filter @aeogen/shared build` and commit the result.");
  process.exit(1);
}
console.log("drift check: OK");
